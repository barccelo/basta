# Basta

Juego de palabras para jugar en grupo desde un teléfono o una tableta.

## Sitio

https://basta-rueda.barcco.chatgpt.site

## Código

La aplicación completa está en `dist/`: HTML, CSS y JavaScript sin dependencias ni compilación. Se puede servir esa carpeta con cualquier servidor de archivos estáticos. `.openai/hosting.json` conserva la configuración del sitio de ChatGPT Sites.

Incluye tablero adaptable, giro táctil, letras orientadas hacia afuera, temporizador configurable, sonido, vibración, modo libre, jugadores, marcador, 100 categorías en 10 temas y categorías personalizadas. Los temas visuales se cambian desde Ajustes y la elección se guarda en el dispositivo.
